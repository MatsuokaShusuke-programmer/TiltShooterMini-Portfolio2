# ティルトシューターミニ
Joy-Conを傾けて直感的に操作する3Dシューティングゲーム。
※Playには「Nintendo Switch Joy-Con」が必要です。

* **制作人数**:1人

* **制作時間**
  * **初期バージョン**:約8時間
  * **ブラッシュアップ**:約71時間
  * **ブラッシュアップ**:約1時間
* **使用ツール**:Unity
* **ライブラリ**:JoyconLib
* **使用言語**:C#
* **ジャンル**:3DJoy-Conシューティング
* **動画**:https://youtu.be/uTLdnRBoIBU?si=r9ldB9Kvhm_N9li1

## 操作説明
※Joy-Con(1本)を横持ちで操作します。
* 移動:Joy-Conの傾き,スティックの前後
* ショット:SL/SR
* ボタン選択:スティック
* 決定:X/下
